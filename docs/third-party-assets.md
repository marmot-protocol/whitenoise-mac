# Third-Party Assets

## GIPHY

`whitenoise-mac/Assets.xcassets/GiphyLogo.imageset/giphy-logo.png` is the
official GIPHY logo used for the required provider attribution in GIF search.
It is the same file whitenoise-ios ships, sourced from GIPHY's official brand
guidelines:

https://support.giphy.com/hc/en-us/article_attachments/9599173349274

The mark must not be recolored, altered, or used without the accompanying
GIPHY-powered search integration.
